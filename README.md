# 森林麋了鹿

嵌入式开发，方向是智能车与运动控制。从原理图到控制律，从寄存器到闭环曲线。

## 方向

- **整车控制** — 速度环与方向环整定、状态机调度、故障保护
- **电机控制** — 无刷 BLDC 换相、编码器测速、PID 闭环调参
- **机器视觉** — 图像采集、赛道元素识别
- **硬件设计** — 核心板与驱动板的原理图、PCB 布局布线

## 工程实践

| 习惯 | 做法 |
| --- | --- |
| 模块化 | 感知 / 决策 / 执行分层，模块通过明确 API 交互 |
| 可追溯 | 关键项目保留 `history/` 历史版本，对照实现演进 |
| 可复现 | 只归档源码与工程配置，剔除编译产物和第三方 SDK |
| 现场调参 | 菜单 + 上位机波形 + Flash 掉电保存，不靠反复烧录 |
| 文档先行 | 保留调用树分析、引脚汇总、技术报告与版本变更记录 |
