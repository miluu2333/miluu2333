# 森林麋了鹿

**运动控制 / Motion Control** — 从功率级驱动到闭环曲线。

把控制律从代码调成实机上稳定、可复现的响应，这是我一直在做的事。竞赛整车只是载体：真正沉淀下来的是一整条链路，从编码器与 IMU 的反馈量测，到固定周期调度、双环整定与限幅，再到无感换相与在线整定，最后落到能回看、能回归的工程记录。下一阶段把这套能力往通用运动控制收敛。

编码器 / IMU / 摄像头 → 滤波与状态估计 → 状态机与元素识别 → 双环 PID 与限幅 → BLDC / 舵机 / 风扇 → 波形回看与在线整定

## 主攻方向：运动控制

| 层次 | 关注点 | 已有实现 |
| --- | --- | --- |
| 感知与反馈 | 位置、速度、姿态的量测与预处理 | 光电编码器外部中断测速 · MPU6050 姿态解算 · 加权滤波 · 摄像头赛道偏差 · ADC 电感 · 超声波 |
| 估计与决策 | 从量测到可执行状态 | 状态机调度 · 赛道元素识别 · 丢线与超时保护 · 故障保护 |
| 控制与整定 | 让执行机构跟上且不过冲 | 增量式 / 位置式 PID · 速度环与方向环 · 限幅与定点化 · 插值查找表 · 菜单在线调参 |
| 驱动与执行 | 把控制量变成真实的力 | 无感 BLDC 过零检测与正弦启动 · 直流电机 PWM · 舵机 · 下压力风扇 |
| 验证与工程化 | 让结果可复现、可回归 | 虚拟示波器波形 · Flash 参数保存 · 分层模块 API · 源码级校验脚本 |

## 工程习惯

| 原则 | 做法 |
| --- | --- |
| 行为不变优先 | 没有实车验证条件，不动控制律、PID 参数、引脚分配、中断配置；现场绕过校验改成编译期开关，默认保持原行为 |
| 只改自研代码 | 逐飞、ST、Infineon 官方库与 `history/` 快照不动；保留记录设计决策的中文注释标记 |
| 字节级纪律 | 604 个 GBK 历史文件按单字节映射读写，不经过编码转换，中文注释不会被写成替换符 |
| 每轮可回归 | 改完跑括号平衡、危险函数残留、头文件守卫、行尾空格、编码完整性自检，再提交 |
| 现场可整定 | 菜单 + 上位机波形 + Flash 掉电保存，不靠反复烧录 |
